# Contributing

If you'd like to see a feature added, then we'd love to have your contribution!

Development happens [on GitHub](https://github.com/the-astrosky-ecosystem/nebra). Check to see if an issue has been created to request a given feature; if not, make one, and we'll discuss it there.

You should follow [The Astrosky Ecosystem's style guide](https://github.com/the-astrosky-ecosystem/development-guide?tab=readme-ov-file#workflows-and-standards) with any code or docs that you contribute.

The package is a project of [The Astrosky Ecosystem](https://github.com/the-astrosky-ecosystem), and it is currently maintained by [Emily Hunt](https://github.com/emilyhunt).
