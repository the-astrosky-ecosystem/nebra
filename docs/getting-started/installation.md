# Installation

## Prerequisites
- Python 3.11 or later

## Install Nebra

### From PyPI
```bash
pip install nebra
```

### From Source

We recommend using [uv](https://docs.astral.sh/uv/) to manage dependencies.

```bash
git clone https://github.com/the-astrosky-ecosystem/nebra
cd nebra
uv sync
```

### Developing

As above, but be sure to install development dependencies with the `--all-extras` flag:

```bash
git clone https://github.com/the-astrosky-ecosystem/nebra
cd nebra
uv sync --all-extras
```
