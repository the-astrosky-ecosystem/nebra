# ATProtocol Overview

The **ATProtocol** (Authenticated Transfer Protocol) is a decentralized protocol for large-scale distributed social applications. It is the backbone of [Bluesky](https://blueskyweb.xyz/), a social media platform built on open standards.

## Key Concepts

### Decentralization
- The ATProtocol is **decentralized**, meaning no single entity controls the network.
- Data is stored in **personal data repositories (PDS)**, which users control.

### Data Model
- Data is stored as **records** in a user's repository.
- Records can be **posts, likes, follows, or custom data types** (e.g., scientific observations).

### Identity
- Users are identified by **DIDs (Decentralized Identifiers)**.
- DIDs are portable and not tied to a specific service.

### Federation
- The ATProtocol is **federated**, meaning multiple services can interoperate.
- Users can **migrate their data** between services without losing their identity or content.

## Why Use the ATProtocol for Scientific Data?
- **Free and Open**: No cost to use, and the protocol is open-source.
- **Scalable**: Designed to handle large-scale data sharing.
- **Reliable**: Built-in redundancy and fault tolerance.
- **Interoperable**: Works with any service that implements the protocol.
