# Nebra: Stream Scientific Data on the ATProtocol

Nebra is a Python library for streaming or sending time-critical scientific data live and for free on the [ATProtocol](https://atproto.com/).

## Key Features
- **Send data**: Share scientific observations or results in real-time.
- **Stream data**: Continuously broadcast data to subscribers.
- **Rebroadcast data**: Relay data from other sources to your audience.

## Why Nebra?
The ATProtocol is a decentralized, open-source protocol for large-scale distributed social applications. Nebra leverages this protocol to provide a **free, reliable, and scalable** way to share scientific data.
