# Report an Issue

If you encounter a bug or have a feature request, please report it on the [GitHub Issues](https://github.com/emilyhunt/nebra/issues) page.

## How to Report an Issue
1. **Check for existing issues**: Search the [GitHub Issues](https://github.com/emilyhunt/nebra/issues) page to see if your issue has already been reported.
2. **Provide details**: Include the following information in your report:
   - A clear and descriptive title.
   - Steps to reproduce the issue.
   - Expected and actual behavior.
   - Python version and operating system.
   - Any relevant logs or error messages.
